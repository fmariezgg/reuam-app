# ReUAM

**ReUAM** es una aplicación móvil académica orientada a la comunidad estudiantil de la Universidad Americana (UAM). Su propósito es facilitar la reutilización, intercambio, donación, préstamo o venta simbólica de artículos académicos y personales dentro del entorno universitario.

El proyecto busca promover la sostenibilidad, el ahorro estudiantil y la economía circular mediante una plataforma sencilla, segura y enfocada en las necesidades reales de los estudiantes.

## Objetivo

Desarrollar una aplicación móvil que permita a los estudiantes publicar, buscar y gestionar artículos reutilizables dentro de la comunidad universitaria, fomentando el consumo responsable y la reducción del desperdicio.

## Funcionalidades principales

* Inicio de sesión institucional.
* Publicación de artículos reutilizables.
* Consulta de artículos disponibles.
* Búsqueda y filtrado de publicaciones.
* Solicitudes de interés entre usuarios.
* Gestión de publicaciones propias.
* Panel administrativo básico.

## Arquitectura

El proyecto sigue una arquitectura basada en **MVVM**, separando responsabilidades para mejorar la mantenibilidad, escalabilidad y organización del código.

```text
mobile-app/
├── presentation/   # Pantallas, componentes UI y ViewModels
├── domain/         # Modelos de negocio y casos de uso
└── data/           # Repositorios, fuentes de datos y servicios externos
```

## Gestión del proyecto

La planificación y seguimiento de tareas se realizará mediante **Jira**, organizando el desarrollo en historias de usuario, tareas técnicas y avances por sprint.
